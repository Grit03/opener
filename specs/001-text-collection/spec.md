# 번역할 본문 수집

## 개요

웹페이지에서 사용자가 읽는 번역할 본문(첫 기능은 영어 기준)을 문단 단위로 수집한다. 수집 결과는 이후 원문 아래에 결과를 표시하는 기능에서 사용한다. 이 단계에서는 페이지 내용을 변경하거나 화면에 새 요소를 추가하지 않는다.

## 사용자 시나리오

1. 사용자가 영어 문서를 열면 제목, 문단, 목록, 표의 글이 읽는 순서대로 수집된다.
2. 문장 안의 링크와 강조 문구는 주변 글과 함께 하나의 문단으로 수집된다.
3. 입력란, 숨겨진 내용, 번역 금지 영역, 코드 블록은 수집되지 않는다.
4. 같은 문서를 다시 확인해도 동일한 위치의 글이 중복으로 쌓이지 않는다.

## 기능 요구사항

- R1. 본문 영역이 있으면 그 안의 글을 우선하고, 없으면 문서에서 읽을 수 있는 글을 수집한다.
- R2. 제목, 문단, 목록 항목, 표의 칸은 서로 다른 수집 단위로 구분한다.
- R3. `br` 줄바꿈은 수집 단위를 나누며, 링크와 강조처럼 문장 안에 이어지는 글은 하나로 묶는다.
- R4. 수집 결과는 DOM 문서 순서를 유지한다. CSS로 바뀐 시각적 순서는 따로 계산하지 않는다.
- R5. 입력 요소와 사용자가 편집할 수 있는 영역은 제외한다.
- R6. 숨겨진 내용과 번역하지 않도록 표시된 영역은 제외한다.
- R7. 코드 블록과 별도 문서나 비문자 콘텐츠는 제외한다. 문장 안의 짧은 코드는 주변 글과 함께 수집한다.
- R8. 영어로 표시된 영역은 포함하고, 다른 언어로 표시된 영역은 제외한다. 언어 표시가 없으면 수집 후보로 본다.
- R9. 빈 글은 제외하고, 한 번의 호출에서 같은 DOM 위치를 두 번 수집하지 않는다. 호출마다 새 결과를 반환한다.
- R10. 수집 과정에서 원문의 글, 요소, 링크와 사용자 입력값을 변경하지 않는다.

## 제외 범위

- 수집한 글을 페이지에 표시하는 기능
- 페이지가 열린 뒤 추가되거나 수정된 글의 감지
- 번역 실행과 언어 선택
- 버튼과 설정 화면
- PDF, 이미지, 자막, 프레임 내부 문서

## 완료 조건

- C1. `<p>Hello <a href="/world">world</a>!</p>`는 `Hello world!` 하나로 수집되며, 원문의 링크는 그대로 유지된다.
- C2. 여러 문단, 목록 항목, 표의 칸이 원래 순서와 경계를 유지한다.
- C3. 입력란, 숨겨진 내용, 번역 금지 영역과 코드 블록이 결과에 포함되지 않는다.
- C4. 영어와 다른 언어가 명시된 영역을 구분한다.
- C5. 같은 문서를 반복해서 확인해도 각 호출의 결과에는 동일한 위치의 글이 한 번만 포함되며, 이전 결과에 누적되지 않는다.
- C6. 수집 전후에 원문 요소와 사용자 입력값이 그대로 유지된다.
